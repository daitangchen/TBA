# TBA 模拟器 · 篮途

![标题页](docs/screenshots/title.png)

高三这一年，体育课只有四十分钟，考试周却能天天打球。

你扮演「大娘」——建队核心之一，场上的大前锋。这里没有固定阵容：**每场比赛前，两位领袖都要从到场的 15 人里重新选人**。

> 当前版本 **v1.1.5**：只开放「大娘」一个角色，奶龙与走刀待解锁。

## 开始玩

- **在线**：<https://daitangchen.github.io/TBA/>
- **本地**：下载仓库后双击 `index.html`，不需要服务器、不需要安装依赖。

## 这一版有什么

| 系统 | 说明 |
| --- | --- |
| 赛历 | 完全按 `schedule.md` 还原：暑假 / 寒假、留校、体育课、小考试、大考试、留校最后一天不打 |
| 到场 15 人 | 每场比赛前生成当天名单：**锋线全来，后卫随机来，客串球员只在考试期间出现**，总数固定 15（含领袖） |
| 每场组队 | 两位领袖轮流选人，各选 5 人 + 自己共 6 人；每场阵容都不一样，没有固定队伍 |
| 比赛 | 3v3、先到 21 分且领先 2 分；领袖必首发，其余自动轮换，产出得分 / 篮板 / 助攻与关键回合 |
| 高三线 | 2025.7.2 暑假留校开局，2026.6.9 高考结束，赛季同日收官 |
| 老师点评 | 常规上学日每天一位老师点评，赛后结算再补一句输赢点评 |
| 养成 | 全班加练、体力、伤病、随机校园事件 |
| 存档 | 浏览器 localStorage 自动保存，刷新后继续 |

## 数据与规则来源

| 文件 | 用途 |
| --- | --- |
| `球员信息表.et` | 22 名球员的姓名、身份、位置、身高、体重；6 位老师作为剧情 NPC |
| `rules.png` | 建队核心（大娘 / 奶龙 / 走刀）与联盟规则参考 |
| `schedule.md` | 赛季时间轴与「哪天能打球」的全部规则 |

### 属性怎么来的

球员信息表里只有身高、体重、位置，所以七项属性（投篮、三分、篮板、速度、力量、防守、体能）由它们推导，再用名字做稳定抖动，保证同一名球员每次开档数值一致：

- 力量、篮板随身高体重上升；
- 速度随身高体重下降，后卫有加成；
- 特性来自表格里预留的「特性一（球场特性）」列，目前是这一版的设计填充。

### 规则实现说明

- **每场 15 人**：6 名锋线（含三位领袖）一定到场；再从后卫里随机抽 9 人。常规日只有 11 名常驻后卫，所以每次会有 2 人「没来」；考试期间客串球员加入候选，可能顶替后卫的位置。
- **每场组队**：两位领袖从池子里轮流选人（先手随机），各选 5 人，加上自己共 6 人；两边不能重复，选满才能开球。
- **首发**：6 人里按综合和体力自动排 3 人，领袖必首发；比赛中会轮换替补。
- **考试周**：每天晚上都能打球，而且是客串球员唯一会出现的时间段。
- **旧版赛季选秀已移除**：`rules.png` 里的 ABC 批次、锁定、中期选秀属于「固定阵容」模型，和这一版「每场重新组队」冲突，因此不再出现在游戏流程里。
- **交易市场**（`rules.png` 第③条）仍未实现。

## 操作

- 日历上的绿点表示可以打球的日子，鼠标悬停可以看到当天的规则。
- 可打球日可以「约战」或「全班加练」，其他日子只能休息或快进。
- 点「约战」后进入组队界面：轮到你时点球员卡选人，选满 5 人后开球。
- 点击右侧「上一场出场阵容」里的球员，可以查看属性详情。
- `Esc` 关闭弹窗。

## 开发

```
index.html                 入口（双击即玩）
assets/css/style.css       全部样式
assets/js/data.js          球员、赛历、老师台词、事件、配置（改数据先看这里）
assets/js/core.js          日历判定、属性、15 人池、组队、比赛模拟、存档
assets/js/ui.js            界面渲染与交互
tests/test-core.js         赛历 / 15 人池 / 组队 / 比赛 / 整季推进
docs/screenshots/          截图
```

跑测试（只需要 Node）：

```bash
node tests/test-core.js
```

### 演示参数

给截图和演示用，会直接跳过标题页（注意：会覆盖本地存档）：

- `index.html?demo=main` 直接进入赛季（打完一场）
- `index.html?demo=team` 打开赛前组队界面
- `index.html?demo=match` 直接看一场比赛结算
- `index.html?demo=school` 停在正常上学日（看老师点评）
- `index.html?demo=schoolmatch` 在上学日打一场并看赛后点评
- `index.html?demo=end` 快进到高考结束
